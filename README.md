# NLP文本分类 - 公司类型分类模型

## 项目概述

本项目为投资公司开发了一个基于NLP的文本分类模型，用于自动识别和分类市场上的公司类型。模型可以将公司描述文本分类到10种预定义的公司类型（0-9）。

## 项目要求

- **输入**: 公司描述文本
- **输出**: 公司类型（0-9）
- **准确率要求**: ≥ 80%
- **训练数据**: `training.csv`（第一列为类型标签0-9，第二列为公司描述）
- **测试数据**: `testing.csv`（用于评估模型准确率）

## 技术栈

- **Python 3.8+**
- **scikit-learn**: 机器学习框架
- **pandas**: 数据处理
- **jieba**: 中文分词
- **TF-IDF**: 文本特征提取
- **多种分类器**: SVM、逻辑回归、朴素贝叶斯、随机森林

## 使用方法

### 1. 配置数据路径

编辑 `config.py` 文件，设置正确的数据文件路径：

```python
DATA_DIR = r"你的数据文件路径"
TRAINING_DATA = os.path.join(DATA_DIR, "training.csv")
TESTING_DATA = os.path.join(DATA_DIR, "testing.csv")
```

### 2. 运行训练

```bash
python main.py
```

程序将自动：
1. 加载训练和测试数据
2. 预处理文本（分词、清洗）
3. 训练模型并自动调参
4. 评估模型准确率
5. 如果准确率 < 80%，自动重新调参训练
6. 保存模型和结果

### 3. 查看结果

训练完成后，结果将保存在：
- **模型文件**: `models/classifier_YYYYMMDD_HHMMSS.pkl`
- **结果文件**: `results/results_YYYYMMDD_HHMMSS.json`

结果文件包含：
- 模型准确率
- 分类报告（精确率、召回率、F1分数）
- 混淆矩阵
- 模型参数

## 模型特点

### 1. 多种分类器支持
- **SVM (LinearSVC)**: 线性支持向量机，适合高维稀疏数据
- **逻辑回归 (LogisticRegression)**: 概率输出，易于解释
- **朴素贝叶斯 (MultinomialNB)**: 快速训练，适合文本分类
- **随机森林 (RandomForestClassifier)**: 集成学习，鲁棒性强

### 2. 自动超参数调优
- 使用网格搜索（GridSearchCV）自动寻找最佳参数
- 5折交叉验证确保模型泛化能力
- 支持多种参数组合

### 3. 文本预处理
- 中文分词（jieba）
- 特殊字符清理
- TF-IDF特征提取
- N-gram特征（1-gram和2-gram）

### 4. 自动重训练机制
- 如果准确率 < 80%，自动尝试不同分类器和参数
- 最多迭代10次，直到达到要求或达到最大迭代次数

## 评估指标

模型评估使用以下指标：
- **准确率 (Accuracy)**: 整体分类正确率
- **精确率 (Precision)**: 每个类别的精确率
- **召回率 (Recall)**: 每个类别的召回率
- **F1分数 (F1-Score)**: 精确率和召回率的调和平均
- **混淆矩阵 (Confusion Matrix)**: 各类别分类情况

## 注意事项

1. **数据格式**: 确保CSV文件格式正确，第一列为类型标签（0-9），第二列为文本描述
2. **编码问题**: 数据文件应使用UTF-8编码
3. **内存要求**: 大规模数据可能需要较大内存
4. **训练时间**: 自动调参可能需要较长时间，请耐心等待

## 故障排除

### 问题1: 数据文件找不到
- 检查 `config.py` 中的数据路径是否正确
- 确保文件路径使用原始字符串（r"..."）或双反斜杠

### 问题2: 准确率始终低于80%
- 检查数据质量，确保标签正确
- 尝试调整 `config.py` 中的参数（min_df, max_df等）
- 增加训练数据量

### 问题3: 内存不足
- 减少 `max_features` 参数
- 使用更小的 `ngram_range`
- 分批处理数据
